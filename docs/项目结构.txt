## 核心功能模块说明

### 前端功能模块

#### 用户系统模块
- **Login.vue / Register.vue**: 用户登录注册页面
- **Personal.vue**: 个人信息管理页面（昵称、头像、标签）
- **Tags.vue**: 标签选择页面（首次登录）
- **CheckInCard.vue**: 每日打卡卡片组件

#### 自习室管理模块
- **Home.vue**: 首页，显示自习室列表和创建入口
- **StudyRoom.vue**: 自习室列表页面
- **StudyRoomDetail.vue**: 自习室详情页面，包含实时通信和AI检测

#### 收藏夹模块
- **BookmarkPanel.vue**: 收藏夹面板组件，支持添加、筛选、删除收藏

#### 组件库
- **CommonToast.vue**: 通用提示组件
- **PrivacyMode.vue**: 隐私模式切换组件
- **StudyRoomList.vue**: 自习室列表展示组件
- **EditAvatar.vue**: 头像编辑组件

#### Composables（逻辑复用）
- **useCamera.js**: 摄像头访问和管理逻辑
- **useWebSocket.js**: WebSocket连接管理
- **useWebRTC.js**: WebRTC视频通信（预留扩展）
- **useRoomData.js**: 房间数据轮询和状态管理
- **useAiDetection.js**: AI检测逻辑封装
- **useRoomSignaling.js**: 房间信令通信管理

#### API接口层
- **client.js**: Axios实例配置
- **user.js**: 用户相关API调用
- **studyRoom.js**: 自习室相关API调用
- **duration.js**: 学习时长相关API调用
- **bookmark.js**: 收藏夹相关API调用

### 后端功能模块

#### 控制器层 (Controllers)
- **user_controller.py**: 用户注册、登录、信息管理、每日打卡接口
- **room_controller.py**: 自习室创建、加入、管理、AI人脸检测接口
- **duration_controller.py**: 学习时长统计、日/周/月排行榜接口
- **bookmark_controller.py**: 收藏夹增删改查接口

#### 服务层 (Services)
- **user_service.py**: 用户业务逻辑处理
- **room_service.py**: 自习室业务逻辑处理
- **duration_service.py**: 学习时长业务逻辑处理
- **bookmark_service.py**: 收藏夹业务逻辑处理
- **check_in_service.py**: 打卡业务逻辑处理
- **ai_service.py**: AI检测服务接口（OpenCV Haar Cascade）

#### 数据模型层 (Models)
- **user.py**: 用户数据模型
- **study_room.py**: 自习室数据模型
- **room_user.py**: 房间用户关系模型
- **study_duration.py**: 学习时长数据模型
- **bookmark.py**: 收藏夹数据模型
- **check_in.py**: 打卡记录数据模型

#### 工具层 (Utils)
- **auth.py**: JWT认证和权限验证
- **cache.py**: Redis缓存操作封装（房间元信息、成员集合、活跃用户检查等）
- **ws_client.py**: WebSocket客户端管理

#### WebSocket服务
- **server.py**: WebSocket连接管理和消息广播（连接管理、信令转发）

#### 配置层 (Config)
- **db.py**: 数据库连接配置（支持MySQL/SQLite）
- **settings.py**: 应用配置管理（JWT、Redis、环境变量）
- **ws.py**: WebSocket配置

#### 定时任务 (Schedule)
- **duration_schedule.py**: 学习时长定时记录任务

## API接口总览

### 用户接口 `/api/user`
- POST /api/user/register - 用户注册
- POST /api/user/login - 用户登录
- POST /api/user/logout - 用户退出
- GET /api/user/profile - 获取用户信息
- PUT /api/user/profile/nickname - 更新昵称
- PUT /api/user/profile/tags - 更新标签
- PUT /api/user/profile/avatar - 更新头像
- GET /api/user/tags - 获取系统标签
- GET /api/user/info/{user_id} - 获取指定用户信息
- POST /api/user/check-in - 每日打卡
- GET /api/user/check-in/status - 获取打卡状态

### 自习室接口 `/api/room`
- POST /api/room/create - 创建自习室
- GET /api/room/list - 列出空闲自习室
- POST /api/room/join - 加入自习室
- POST /api/room/leave - 离开自习室
- GET /api/room/info/{room_id} - 获取房间信息
- PUT /api/room/update/{room_id} - 更新房间信息
- DELETE /api/room/destroy/{room_id} - 销毁房间
- POST /api/room/detect-person - AI人脸检测

### 学习时长接口 `/api/duration`
- GET /api/duration/daily - 获取每日学习时长
- GET /api/duration/weekly - 获取近7天学习时长
- GET /api/duration/rank - 获取学习时长排行榜
- GET /api/duration/rank/weekly - 获取周排行榜
- GET /api/duration/rank/monthly - 获取月排行榜
- GET /api/duration/period/summary - 获取时间段学习时长汇总

### 收藏夹接口 `/api/bookmark`
- POST /api/bookmark - 创建收藏
- GET /api/bookmark - 获取收藏列表
- GET /api/bookmark/tags - 获取所有标签
- PUT /api/bookmark/{id}/tags - 更新收藏标签
- DELETE /api/bookmark/{id} - 删除收藏
- DELETE /api/bookmark/tag/{tag} - 删除标签

### WebSocket接口
- ws://host/ws/room/{room_id}?user_id={user_id} - 房间实时通信

## 数据库设计

### 表结构
- **user**: 用户信息表
- **study_room**: 自习室表
- **room_user**: 自习室成员表
- **study_duration**: 学习时长表
- **bookmark**: 收藏夹表
- **check_in**: 打卡记录表

### 关系说明
- User 1:N RoomUser（用户可以有多个自习室记录）
- StudyRoom 1:N RoomUser（自习室可以有多个成员）
- User 1:N StudyDuration（用户可以有多个时长记录）
- User 1:N Bookmark（用户可以有多个收藏）
- User 1:N CheckIn（用户可以有多个打卡记录）

## 技术架构特点

### 前端架构优势
- **组件化设计**: 高内聚低耦合，便于维护和测试
- **Composition API**: 逻辑复用，代码组织清晰
- **响应式设计**: 适配不同设备，用户体验良好
- **Composables模式**: 逻辑分离，状态管理集中

### 后端架构优势
- **异步框架**: FastAPI提供高性能API服务
- **分层架构**: 控制器-服务-模型分层清晰
- **缓存优化**: Redis提升实时性能（默认fakeredis模拟）
- **WebSocket支持**: 实时通信能力强大

### 数据库设计
- **关系型数据库**: MySQL/SQLite支持事务一致性
- **缓存层**: Redis提供高速数据访问
- **数据模型**: 合理的表结构和关系设计

## 部署和运维

### 开发环境
- 前端: Vite开发服务器 + 热重载
- 后端: Uvicorn开发服务器 + 自动重载
- 数据库: SQLite（默认）或本地MySQL
- 缓存: fakeredis（默认）或Redis

### 生产环境
- 前端: Nginx静态文件服务
- 后端: Uvicorn + Gunicorn多进程
- 数据库: MySQL集群
- 缓存: Redis集群
